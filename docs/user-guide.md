# User guide

Written for authors, not engineers: no JSON, no prompts.

## Principles the UI follows
- **Flag, never block.** Nothing stops you writing; strictness only changes what is flagged.
- **Every flag shows its evidence**: your text, the canon it conflicts with, and where that came from.
- **One click out.** Fix, Intentional, or Change rule on every flag. Intentional is remembered.
- **Nothing becomes canon until you approve it.**

Screen-by-screen instructions are written once the screens are wired to the pipeline.
